## 1. 最終目的（Notionの記載どおり）

家庭教師を探す人だけでなく、**子どもの学習に関わる全利用者**を集める。

| 利用者 | 主な目的 |
|---|---|
| 小中高生 | 無料の学習・進路ツール、講師・講座 |
| 保護者 | 講師選び、学習状況の把握 |
| 大学生・社会人講師 | 仕事、実績の蓄積、記事執筆 |
| 塾・予備校 | 講座掲載、法人公式投稿 |
| 教材会社・出版社 | 教材掲載、広告 |
| 大学・教育機関 | 学部学科情報、公式投稿 |

### 利用が循環する流れ

```
無料コンテンツ（漫画・記事・大学検索・単語帳）
  ↓
共通アカウント登録
  ↓
学習・進路データの蓄積（共通User ID＋共通タグ）
  ↓
記事・教材・講師の推薦（理由を明示）
  ↓
家庭教師・講座・模試（有料取引）
  ↓
法人広告・教材購入（PR表示つき）
  ↓（収益と実績が信用スコアへ戻り、推薦の質が上がる）
```

## 2. 全体構造：3層モデル（提案）

17事業を平置きにせず、**共通基盤 → 事業モジュール → 集客**の3層に分ける。

### 第1層：共通基盤（全事業が必ず使う。各事業で作り直さない）

| 基盤 | 内容 | 既存コードの状況 |
|---|---|---|
| ID・認証 | 共通User ID、ログイン、メール認証 | ✅ 実装済み（Supabase Auth） |
| アカウント種別 | 生徒・保護者・講師・法人・運営 | ⚠ 生徒・講師・運営のみ。保護者はDB定義だけ、法人はなし |
| 保護者-子の紐付け | 保護者が複数の子を管理し、同意する | ❌ なし |
| 同意管理 | 規約、プライバシー、保護者同意、講師への共有許可、AI学習利用の可否 | ⚠ 規約・プライバシーの同意のみ |
| 共通タグ | 科目・単元・試験・学年・大学・学部学科 | ⚠ 講師の科目ラベルのみ |
| 学習履歴 | 各事業の結果を同じ形式で記録する（模試、単語、添削、授業） | ⚠ 授業記録のみ |
| コンテンツ来歴 | AI生成か、版番号、確認者、確認状態、訂正履歴 | ❌ なし |
| 表示区分 | 自然表示 / 運営推薦 / PR / 広告 | ❌ なし |
| 信用スコア | 講師・記事・教材・投稿などの評価 | ⚠ ランク定義のみ（ページは停止中） |
| 決済 | 年額利用料、講座、模試 | ❌ なし |
| 通知 | メール、サイト内通知 | ⚠ 予約メールのみ |
| 通報・モデレーション | 通報、非表示、アカウント停止 | ❌ なし |
| 計測 | 登録率、再訪率、事業間の移動 | ❌ なし |

### 第2層：事業モジュール（役割ごとに5分類）

| 分類 | 事業 | 役割 |
|---|---|---|
| **A. 取引（収益の中心）** | 家庭教師マッチング、サイト内塾、模試開催 | 人と人の授業・試験が成立する |
| **B. 無料コンテンツ（入口）** | 記事集、科学漫画、大学・学部・学科検索 | 検索とSNSから人を集める |
| **C. AI学習ツール** | AI単語帳、AI添削、AI志願書審査、AI面接、AI指導計画 | 無料でも価値があり、学習履歴を生む |
| **D. 制作（裏方）** | 模試制作 | 問題を作って、模試開催・単語帳・添削へ供給する |
| **E. 信用・収益補助** | ランキング・信用スコア、教材DB・アフィリエイト | 推薦の公正さと副収益 |
| **F. コミュニティ** | 教育版X | 最後に開く。蓄積があってから |

### 第3層：集客

| 事業 | 役割 |
|---|---|
| SNS戦略（外部） | X、Instagram、YouTube Shorts、TikTokからB群へ人を送る |
| 教育版X（内部） | サイト内で投稿・交流させて定着させる（F群） |

Notionの方針どおり、**外部集客（SNS戦略）と内部SNS（教育版X）は別の事業として扱う**。

## 3. 事業間のデータの流れ

Notionの各ページにある「他機能との接続」をまとめたもの。**どの事業も共通User IDと共通タグを通じてつながる**ため、これが第1層を先に固める理由になる。

```
大学検索 ──志望校リスト──→ 志願書審査 ──弱い箇所──→ AI面接
   │                          │                       │
   │                          └──表現──→ AI添削        │
   └──志望校──→ 模試開催 ←──問題── 模試制作            │
                  │                                     │
                  ├──弱点（単元タグ）──→ AI単語帳       │
                  ├──弱点──→ 教材DB（無料教材を先に表示）│
                  └──弱点──→ AI指導計画 ←──回答できなかった内容
                                 ↑
                AI添削・単語帳の履歴 ┘
                                 ↓ 講師の承認
                          家庭教師・サイト内塾
                                 ↓ 授業実績・評価
                          ランキング・信用スコア
                                 ↓
                   講師の推薦順・称号（記事集・教育版Xにも表示）
```

**共通タグの最小セット（提案）**：科目 / 単元 / 試験（共通テスト・英検・TOEFLなど） / 学年 / 大学・学部・学科 / 技能（読む・聞く・書く・話す）

## 4. AIと人間の責任分担（Notionの方針から抽出）

| 事業 | AIが担当 | 人間が必ず確認・決定 |
|---|---|---|
| 模試制作 | 問題・解説の初稿 | 正答の検証は制作役とは別の人。誤問のない状態で公開 |
| 模試開催 | 結果の説明文 | 採点はAIではなく正答データとの照合ルールで行う |
| 科学漫画 | 構成案・作画 | 科学的な正確さ、安全性、公開の判断 |
| AI単語帳 | 例文・長文・問題 | 大量公開の前に審査する |
| AI添削・志願書審査 | 指摘・改善の方向 | 代筆しない。重要な提出前は講師や先生が確認する |
| AI面接 | 質問・追加質問・項目別評価 | 合否予測ではないと明示する |
| AI指導計画 | 計画の初稿 | **講師の承認が必須** |
| 信用スコア | 計算・不正の検知 | 算定軸の公開、異議申立ての審査 |
| SNS | 投稿案 | 重要な対外発言は角田さんか運営が承認 |

全事業で共通：**AI出力には生成バージョンと確認状態を残す**（第1層の「コンテンツ来歴」）。

## 5. 開放段階（Notionの5段階に、開放条件を足した案）

Notionの段階分けは維持し、**次の段階へ進む条件（ゲート）**を加える。数値は仮の値で、決めるのは角田さん。

| 段階 | 開く事業 | 先に必要な共通基盤 | 次へ進む条件（仮） |
|---|---|---|---|
| **1** | サイト公開（家庭教師）、記事集、大学検索 | ID・権限・保護者紐付け・同意・通報・停止スイッチ | 認証済み講師○人、相談開始○件、30日以内の再訪率○% |
| **2** | 科学漫画、AI単語帳、AI添削、AI志願書審査 | 共通タグ・学習履歴・コンテンツ来歴・AI原価の上限 | 無料ツールの月間利用者○人 |
| **3** | 教材DB・アフィリエイト、AI面接、AI指導計画、ランキング | 表示区分・信用スコア・音声データの保存設定 | 授業実績が○件に達し、ランクに意味が出る |
| **4** | 模試制作（本格版）、模試開催、サイト内塾 | 決済・返金規則・スタッフ管理 | Notionの記載：総利用者5,000人以上、仮参加の希望者150人以上 など |
| **5** | 教育版X、法人アカウント、広告配信、高度な推薦 | 法人アカウント・モデレーション体制・広告管理 | Notionの記載：空のタイムラインにならない量の蓄積 |

> 注：模試制作の「共通テスト型リスニングの小さな演習」は、段階2の無料コンテンツとして先に出す選択肢もある（Notionに「一度制作すれば配信時のAI原価が小さい」とある）。判断は角田さん。

## 7. 教育プラットフォームの範囲外として分けるべきもの（提案）

Notionの同じ階層に次の構想が入っていますが、**教育プラットフォームとは対象者もブランドも違う**ので、別の事業として切り離すことを提案します。

| 構想 | 内容 | 提案 |
|---|---|---|
| スキー事業 | 福島の滑走行程 | 別事業（または個人の計画） |
| X海外向けNEWS／日本発見エンジン | 外国人向けにコンビニ、お菓子、文房具、アニメを案内 | 別事業。共通User IDの対象にも入れない |
| 一般商品アフィリエイト | ゲーミングチェア、マットレスなど | 別事業。教材アフィリエイトと混ぜない |
| YouTube作業BGM（海外向け） | 空 | 別事業 |

例外として、「日本の文房具」と「日本の高校生の日常」は教材DBや記事集と重なる部分があり、将来つなげられる可能性があります。

## 8. 見つかった矛盾・抜け（Notion内／Notionとコード）

### Notionの中
1. **家庭教師マッチングチーフと記事集チーフが、組織図に入っていない**。どちらの版の組織図にもないのに、第1段階の稼働リストと呼び出し例には登場する。
2. 「教育プラットフォーム全体方針」DBに、**記事集とSNS戦略のページがない**。記事集は「家庭教師サイト編集案」の下にある。
3. **「サイト内ランク開始」が空**。一方で「家庭教師サイト ＞ 計算」には具体的な計算式がある。正本がどちらか決まっていない。
4. ポイント計算の気になる点：
   - TOP3・TOP10などの「順位ボーナス」が次の順位計算にも入るなら、上位が固定されやすい循環になる。
   - 「希少分野ボーナス（1授業ごとに+13pt）」には上限がない。
5. DBの列名に「ああ」「ああk！zm」があり、DB名も「全まとめ」と「やりたいこと一覧」で表記が揺れている。進捗・状態・段階の列がない。

### Notionとコード
| Notionの記載 | コードの実態 |
|---|---|
| 公開時に「科目・地域・料金による検索」 | 地域・料金で検索できるかは未確認 |
| 公開時に「評価・レビュー」 | 授業後フィードバックはあるが、公開レビューはない |
| 「通報、アカウント停止、障害時に新規登録や依頼を停止する手段」 | ない |
| 「本番DBのバックアップと復旧方法」 | 文書にない |
| 法人アカウント（塾・教材会社・出版社・大学） | ロールがない |
| 「保護者の許可」で講師へ共有（AI面接・添削など） | 保護者ロールが使われていない |
| ランク：講師・記事・教材・漫画・模試問題・法人投稿が対象 | 講師のみ。7段階のランク定義があり、ランキングページは停止中 |
| 教育版X：未成年者を外部連絡へ誘導させない、電話番号の検知 | チャットに検知機能はない（未確認） |
