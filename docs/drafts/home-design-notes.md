# トップページ 設計メモ（frontend-design の手順に沿って作成）

## 題材
- 題材：korupiyo（得意で選ぶ家庭教師マッチング）
- 対象：中高生の保護者と生徒（次に講師）
- このページの役割：訪問者が「自分のつまずき方に合う先生を探せる」と分かり、先生探しを始めること

## 題材の世界から借りるもの
家庭教師の現場にあるもの：罫線ノート、先生の赤ペン、蛍光ペン、教科書の書体。
→ ページ全体を「よく使い込まれたノートの1ページ」として組む。

書体
- BIZ UDPゴシック：見出しと本文。教科書や学校の配布物にも使われるUD書体で、保護者にも読みやすい
- Klee One：赤ペンの書き込みだけ。先生の手書き文字の役

## レイアウト案
```
A（採用）                         B（不採用：中央寄せのApple型）
+-----------------------------+   +-----------------------------+
| 見出し        | 写真        |   |        見出し（中央）        |
| 説明          |  +ノート  |   |        ボタン                |
| [探す]        |  つまずき   |   |   [大きな製品画面]           |
|               |  →先生の得意|   |                             |
+-----------------------------+   +-----------------------------+
```
- 文字は左揃え。ノートの書き出しと同じ
- ヒーローの主役：つまずきを選ぶと、合う先生の得意が蛍光ペンで示され、赤ペンで理由が書き込まれる「試せる見本」

## 原則
1. 大胆にするのはヒーローの「試せるノート」1か所だけ。他は静かに
2. 赤ペンと蛍光ペンは意味を持つ（赤＝先生の指導・理由、黄＝得意）。飾りには使わない
3. 番号は手順（3段階）にだけ付ける
4. 動きは2つだけ：読み込み時に赤ペンの下線が1回引かれる／つまずきを選んだときに中身が切り替わる

## 見直しで変えたこと（ありがちな選択の排除）
- 生成り色＋朱色 → 白い紙＋罫線＋赤ペン（赤は書き込みにだけ使う）
- 見出しの一語だけを強調 → やめる
- 英大文字のラベル、見出し上の小見出し → やめる
- ボタン文字の「→」→ やめる。ボタンは結果をそのまま書く（「家庭教師を探す」）
- 「・」でつなぐ表記 → やめる
- 同じ角丸カードを並べる → 罫線と余白で区切る
- 全セクションのふわっと出る動き → やめる
- 「アクセサリーを1つ外す」：ヒーローに浮かべていたAIチャットのカードを外した
