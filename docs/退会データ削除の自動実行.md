# 退会データを3か月後に自動削除する設定

この設定は、`purge-withdrawn-accounts` Edge Function を毎日1回実行します。退会から90日を過ぎたアカウントは、認証情報・プロフィール・画像・証明書・予約・チャットを削除します。

## 1. Edge Function の秘密値を登録する

Supabase Dashboard の **Edge Functions → Secrets** で、次を追加します。

- Name: `ACCOUNT_PURGE_CRON_SECRET`
- Value: パスワード管理ツールで作った十分に長いランダム文字列

この値は GitHub、Vercel、ブラウザには置かないでください。

## 2. Supabase SQL Editor で毎日実行を登録する

以下の `YOUR_SECRET` を手順1の値へ置き換え、SQL Editor で一度だけ実行します。`dajgwnijcvdthjnfsolt` はこのサイトのSupabaseプロジェクトIDです。

```sql
select cron.unschedule(jobid)
from cron.job
where jobname = 'purge-withdrawn-accounts-daily';

select cron.schedule(
  'purge-withdrawn-accounts-daily',
  '15 3 * * *',
  $$
    select net.http_post(
      url := 'https://dajgwnijcvdthjnfsolt.supabase.co/functions/v1/purge-withdrawn-accounts',
      headers := jsonb_build_object(
        'Content-Type', 'application/json',
        'x-cron-secret', 'YOUR_SECRET'
      ),
      body := '{}'::jsonb
    );
  $$
);
```

実行前に、`pg_cron` と `pg_net` が有効でない場合は Dashboard の Database → Extensions から有効にします。

## 3. 動作確認

Edge Functions の `purge-withdrawn-accounts` の Logs で、毎日3:15（UTCではなくプロジェクト設定時刻を確認）ごとの呼び出しと `deleted` 件数を確認します。

削除実行前の退会アカウントは、同じメールアドレスで新規登録を始め、メールに届く6桁コードで本人確認した場合のみ復帰できます。
