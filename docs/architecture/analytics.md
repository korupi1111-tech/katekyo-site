## 1. 何を測るか

| 区分 | 指標 | 測り方 |
|---|---|---|
| North Star | 累計登録数（目標 10万／2027-10-21） | **DB（`user_profiles`）で数える**。解析ツールには依存しない（monitoring-and-recovery.md の SQL） |
| 流入 | 訪問数、流入元（検索・X・Instagram 等）、UTM | 解析ツール |
| 導線 | 訪問 → 講師検索 → 講師詳細 → 登録開始 → 登録完了 → 相談開始 | 解析ツールのカスタムイベント |
| SNS効果 | 投稿ごとの登録数（UTM 別） | 解析ツール |

登録数を解析ツールではなくDBで数える理由：広告ブロッカーで解析が欠けても、目標の数字が狂わないため。

## 2. このサイト固有の制約（重要）

ページ切替は `src/App.tsx` の内部状態で行っていて、**URLが変わらない**。そのため、URLを見て自動でページビューを数えるツールでは、全ページが「トップ」1ページとして記録される。

→ どのツールでも、`move()`（ページ切替）のタイミングでカスタムイベントを送る小さなコードが必要。URLルーティングの導入は大きな変更なので、今回は行わない。

## 3. 候補比較

| ツール | 費用（目安） | Cookie | カスタムイベント・導線分析 | 未成年者を含むサイトとの相性 | 評価 |
|---|---|---|---|---|---|
| **PostHog Cloud** | 無料枠 月100万イベント | 使わない設定が可能（メモリ保存） | ◎ イベント・ファネル・UTM | ◎ 自動収集・録画をOFFにし、個人を識別しない設定にできる | **推奨** |
| Umami Cloud | 無料枠あり（小規模向け） | 使わない | ○ イベントあり、ファネルは簡易 | ◎ 収集項目が少ない | 次点（シンプルさ重視なら） |
| Cloudflare Web Analytics | 無料 | 使わない | ✕ カスタムイベントなし | ◎ | 不適（§2 の制約で全ページが1ページになる） |
| Vercel Web Analytics | Hobby は無料枠あり | 使わない | △ カスタムイベントは有料プラン | ◎ | 不適（導線が測れない） |
| Google Analytics 4 | 無料 | 使う | ◎ | △ Cookie同意の検討、Googleの広告機能との連携に注意が必要 | 非推奨 |

### 推奨：PostHog Cloud を次の設定で使う
- Cookie を使わない（`persistence: "memory"`）
- 自動収集（autocapture）、セッション録画、アンケートは OFF
- `identify` を呼ばない（User ID・メールアドレス・氏名を送らない）
- コードから送るのは「ページ名」「イベント名」「アカウント種別（生徒／講師）」だけ
- PostHog が自動で付けるもの：UTM、参照元、URL（クエリ・ハッシュは `before_send` で除去）、IPアドレス、端末・ブラウザ・OS・画面・言語、ページを開いている間だけ有効なランダムID
- PostHog のプロジェクト設定で「Discard client IP data」を有効にする（security-reviewer 必須修正）
- 保存先リージョン：EU または US（どちらでも、プライバシーポリシーに記載する）

費用は無料枠内の想定（10万登録の規模でも、上記の最小イベントなら月100万イベントを超えにくい）。
