# 運営経由の講師問い合わせ 運用手順（16 家庭教師マッチング）

> 作成 2026-10-21。創業者決定：届出の判断が済むまで、講師と生徒のサイト内チャット・授業予約は画面に出さない（コードとDBは残す。`src/lib/features.ts`）。

## 1. 流れ

```
生徒・保護者（ログイン必須）
  └─ 講師プロフィール「この講師について問い合わせる」→ /inquiry/<講師ID>
       フォーム：お名前・返信先メール・学年（任意）・相談内容・同意チェック（必須）
  └─ send-inquiry（既存）→ 運営メール（件名【講師への問い合わせ】<講師名>）＋ inquiries テーブル
運営
  1. 内容を確認（不審・営業目的なら対応しない）
  2. 講師へ SMS またはメールで通知：「問い合わせがあり、仕事用メールアドレスを相手に伝える」
  3. Gmail（korupiyopiyo@gmail.com）から、講師の仕事用メールアドレスを問い合わせ者へ送る
講師と生徒・保護者
  └─ 以降は直接やりとり（日程・授業料。手数料なし）
```

## 2. 運営が送る文面（テンプレート）

### 2-0. 講師の仕事用メールと同意の確認（Supabase SQL Editor・管理者のみ）
問い合わせ本文の「講師ID」を入れて実行する。`share_consent` が false、または行がない場合は連絡先を送らず、講師へ登録を依頼する。
```sql
select tp.display_name, up.account_status, c.work_email, c.share_consent, c.consented_at, c.consent_version
from public.teacher_profiles tp
join public.user_profiles up on up.id = tp.user_id
left join public.teacher_contact_settings c on c.teacher_user_id = tp.user_id
where tp.id = '<講師ID>';
```
- `account_status` が `active` 以外（退会・停止など）の講師の連絡先は送らない。

### 2-1. 講師への通知（SMS／メール）
```
korupiyo運営です。
生徒・保護者の方から、{講師名}先生へのお問い合わせがありました。
相談内容：{科目・目標の要約}
学年：{学年}
先生の仕事用メールアドレス（{仕事用メール}）を、この方へお送りします。
お受けできない場合は、24時間以内にこのメッセージへご返信ください。
```

### 2-2. 問い合わせ者へのメール（Gmail）
```
件名：【korupiyo】{講師名}先生の連絡先のご案内

{お名前} 様

korupiyo運営です。{講師名}先生へのお問い合わせありがとうございました。
先生へ連絡のうえ、先生の仕事用メールアドレスをお知らせします。

  {講師名}先生：{仕事用メール}

日程や授業料は、先生と直接ご相談ください。korupiyoは授業料から手数料をいただきません。
運営は、先生とのやりとりや授業の内容には関与しません。

【安全のためのお願い】
・18歳未満の方は、保護者の方と一緒にやりとりしてください。
・対面の初回授業は、保護者の方の同席をおすすめします。
・不適切な言動があった場合は、サイト下部の「通報する」からお知らせください。

korupiyo運営
```

### 2-3. 送信前チェック（誤送信防止）
- [ ] 宛先が問い合わせのメールアドレスと一致している（コピー＆ペーストで入れる）
- [ ] 講師名と仕事用メールが、問い合わせ本文の「講師ID」の講師のものと一致している
- [ ] 2-0 のSQLで `share_consent = true`・`account_status = active` を確認した
- [ ] 講師へ通知してから24時間たっている（または講師の了承がある）
- [ ] BCC・CC を使っていない
