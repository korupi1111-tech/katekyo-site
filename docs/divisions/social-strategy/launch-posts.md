# 公開告知 投稿キュー（02 SNS戦略）

> 作成 2026-10-21。状態：**全件 承認待ち**。投稿はしない（投稿は創業者が承認後に行う）。
> 媒体：X のみで開始（Notion に「Xカテキョ運用」の構想あり。他媒体は反応を見てから）。
> `{URL}` は公開ドメイン確定後に `https://<DOMAIN>/?utm_source=x&utm_medium=social&utm_campaign=launch&utm_content=<ID>` に置き換える。

## 0. 前提（コード調査で確認した制約）

| 制約 | 影響 | 対応 |
|---|---|---|
| ページ切替でURLが変わらない | 投稿から特定のコラム・検索結果へ直接リンクできない。リンク先は常にトップ | 本文で「サイトの『講師直筆コラム』から読めます」と行き先を書く。直接リンクはURLルーティング導入時（B-22） |
| 公開中の講師は創業者のみ（検索はデモ講師を除外済み） | 生徒向けに「先生が多数」と書けない | 公開直後は **講師募集を先**、生徒向けは「仕組み」と「無料コンテンツ」を中心にする |
| 解析はCookieなし | 投稿を見た人が後日あらためて登録した場合は、どの投稿経由か計測できない | その場で登録した分だけを投稿の成果として数える（過小評価になる） |

## 1. 投稿案

ブランド確認（brand-reviewer の観点、CEO が実施）：✅ 誇張なし ／ ✅ 合格・成績の保証表現なし ／ ✅ 生徒・未成年者の情報なし ／ ✅ 主目的1つ ／ ✅ 事実の根拠あり

### L1（公開告知・固定）
```
家庭教師サイト korupiyo を公開しました。
大学名ではなく「どう教えるか」「どんな生徒に向いているか」で先生を探せます。
授業料からの手数料は0円。いまは無料期間中です。
{URL}
```

### L2（講師募集）
```
家庭教師をしている大学生・社会人の方へ。
korupiyo では、得意な教え方だけでなく「対応しないこと」もプロフィールに書けます。
学歴だけでなく、授業の記録が実績として残ります。
創設期に登録した講師は初年度無料です。
{URL}
```

### L3（コラム紹介）
```
英語を「なんとなく」で読めて、聞き取れる。でも、いざ書くと文法が崩れる。
感覚で英語を身につけた人がぶつかりやすいこの壁について、自分の経験をコラムに書きました。
サイトの「講師直筆コラム」から読めます。
{URL}
```

### L4（保護者向け）
```
保護者の方へ。
korupiyo では、講師とのやりとりはサイト内のチャットで行い、予約や授業の記録も残ります。
気になるプロフィールや行為は、サイト下部の「通報する」から運営に知らせられます。
{URL}
```

### L5（学習のヒント・リンクなし）
```
「解説を読めば分かるのに、初見の問題で手が止まる」
知識が足りないというより、解き始めの方針を決める練習が足りないことがよくあります。
解いたあとに「どこで止まったか」「何を見て方針を決めたか」を一文で書き残すと、次に同じ場面で止まりにくくなります。
```

### L6（投票）
```
家庭教師を探すとき、いちばん知りたいことは？
（サイトの改善に使います）
```
選択肢：教え方 ／ 料金 ／ 授業の実績 ／ 話しやすさ

### L7（ランク制度）
```
korupiyo のランクは、学歴ではなく授業の記録で上がります。
授業回数、授業後の評価、継続を記録し、架空の授業や評価の操作は禁止しています。
ランクは保証ではなく、相性を選ぶための参考情報のひとつです。
{URL}
```

### L8（1週間の開発報告・テンプレート）
```
公開から1週間で korupiyo に追加したこと：
・{追加1}
・{追加2}
・{追加3}
ご意見はサイトのお問い合わせから受け付けています。
{URL}
```
※ 実際にリリースした内容だけで埋める。未リリースの予定は書かない。

## 2. 創業者の判断が必要な案（任意）

### L9（運営者の紹介）
```
korupiyo は、現役の高校3年生が受験勉強と並行して作っています。
自分が「感覚の英語」でつまずいた経験から、学歴より教え方で先生を選べる場所にしたいと考えました。
{URL}
```
- 効果：開発者本人の物語は拡散されやすく、Notion の「開発速度そのものをコンテンツにする」方針とも合う
- 注意：運営者が未成年かどうか、学校が特定されないか、受験期の負担。サイトの講師プロフィールには「現役高校3年生」と既に掲載されている
- **掲載するかは創業者が決める**

## 3. 返信の方針（community-manager）
- 返信案は CEO が作り、創業者が送る。重要な対外発言（料金、規約、トラブル）は必ず創業者が判断する
- 個人の成績や学校名を書き込んだ返信には、公開の場で深掘りしない
- 外部での連絡先交換を求める返信には応じない
